## Этапы

### A — Архитектура и маршрутизация — **DONE**
- `/` → Nexus AI; `/code` → Code Studio; `/code/ide` → прежняя IDE.
- Переключатель «Режим разработчика» (по умолчанию выключен, сохраняется в localStorage). Выключен → в Nexus AI только Chat/Work, `/code` и `/code/ide` показывают предложение включить режим.
- Dexie v1→v2 миграция (аддитивная), тест `fs.test.ts` проходит.
- Проверено: `tsc`, `vitest`, `next build`.

### B — Универсальный AI — **DONE** (с оговорками)
- Chat: отдельный универсальный системный промпт, контекст IDE **не** передаётся, потоковая генерация, остановка, Markdown + подсветка, копирование, редактирование сообщений, повтор генерации, вложения (текстовые файлы), выбор модели (fallback сохранён), история (создать/переименовать/удалить/закрепить/поиск по названию и тексту), сохранение между сессиями.
- Work: сервер-ориентированный агент (план → шаги search/browse/analyze/write → отчёт), журнал действий, изоляция ошибок шагов; скрытые рассуждения модели **не** передаются клиенту.
- Интернет: Auto / Search On / Search Off; провайдеры Tavily → Brave (если есть ключи) → DuckDuckGo HTML → Wikipedia (без ключей); чтение страниц (извлечение текста, дат, ссылок), источники с номерами и датами, защита от prompt injection (изоляция в `<untrusted_source>`, нейтрализация разделителей, детектор инструкций).
- Оговорки: без `TAVILY_API_KEY`/`BRAVE_API_KEY` качество поиска ниже (DuckDuckGo может отдавать защитную страницу — тогда сервер честно сообщает об отсутствии результатов, ничего не выдумывая). Вложения: только текстовые файлы (бесплатные модели не читают PDF/изображения).

- Vercel: проекты, деплои, статусы, логи сборки, создание проекта из GitHub-репо, deploy/redeploy (preview и production с подтверждением), откат production (promote), переменные окружения (значения не возвращаются в браузер).

## Что требует настройки

| Переменная | Назначение | Без неё |
|---|---|---|
| `OPENROUTER_API_KEY` (или `OPENROUTER`) | AI | ИИ недоступен |
| `TAVILY_API_KEY` / `BRAVE_API_KEY` | качественный веб-поиск | DuckDuckGo/Wikipedia (хуже) |
| `BROWSERLESS_URL` + `BROWSERLESS_TOKEN` | чтение JS-сайтов | только обычный HTTP |
| `NEXUS_SESSION_SECRET` | ключ шифрования сессий интеграций | производный от других секретов (рекомендуется задать) |
| `GITHUB_WEBHOOK_SECRET` | приём вебхуков | эндпоинт отвечает 503 |
| `DATABASE_URL` | постоянный аудит | аудит в памяти |
| `NEXUS_ADMIN_KEY` | owner-режим (токены владельца из env) и старые серверные инструменты Nexus | токены владельца не используются |

## Известные ограничения
- Режим разработчика хранится в браузере (localStorage): это переключатель интерфейса, а не защита. Защита серверных операций — cookie-сессии/ключ владельца.
- Лимиты rate limit — in-memory на инстанс (best-effort на serverless).
- DNS-rebinding между проверкой и запросом теоретически возможен; смягчено повторной проверкой каждого редиректа.
- Дневные лимиты бесплатных моделей OpenRouter сохраняются.
