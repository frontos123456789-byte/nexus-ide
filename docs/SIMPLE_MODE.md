# Nexus — простой режим (переработка интерфейса)

## Что сделано
- Новая навигация из пяти пунктов: **Главная · Создать · Мои проекты · AI-чат · Настройки** (на телефоне — нижняя панель, на компьютере — левое меню). Пункт «Режим разработчика» появляется только когда режим включён.
- **Главная** (`/`): большое поле «Что вы хотите сделать?», шесть крупных действий, приветствие при первом запуске (закрывается), «Продолжить работу» (черновики + последние проекты). Фраза из поля определяется по ключевым словам (`src/lib/simple/intent.ts`) и ведёт в нужный мастер или в чат.
- **Мастера** (`/create/site|app|bot|presentation`): 2–3 простых шага, подсказки-варианты, название по умолчанию, черновики сохраняются в браузере (восстановление незавершённой работы).
  - Сайт / дизайн приложения — генерация через ИИ; если ИИ недоступен, сайт можно создать по готовому шаблону.
  - Telegram-бот — 3 шага, пример диалога, пошаговая инструкция BotFather, ключ вставляется в скрытое поле и хранится на сервере зашифрованно (httpOnly-сессия), в интерфейсе не показывается.
  - Презентация — одно поле с темой; число слайдов и оформление подбираются автоматически; при недоступном ИИ — готовый шаблон.
- **Мои проекты** (`/projects`): единый список (сайты, боты, презентации, приложения, прежние презентации из таблицы `decks`), превью, «Открыть», переименовать, копия, удаление с подтверждением.
- **Страница проекта** (`/projects/[id]`): сайт/приложение — крупный предпросмотр, «Изменить» (правка по описанию, «Вернуть как было»), «Опубликовать» (GitHub + Vercel, с объяснением простыми словами; без аккаунтов — «Сохранить» файлом), бот — честный статус, презентация — слайды, «Изменить текст/оформление», «Добавить слайд», «Скачать» (PPTX/PDF), автосохранение.
- **Настройки** (`/settings`): размер текста (100–150 %), аккаунты и подключения, режим разработчика, расширенные настройки ИИ (поиск, модель) — свёрнуты.
- **Режим разработчика** сохранён целиком: `/code` (Центр разработчика, 50 инструментов, Control Center), `/code/ide` (Monaco, файлы, терминал, агенты). Данные те же (IndexedDB `nexus-ide`), миграций нет.
- **Vercel Monitor** убран из навигации Центра разработчика (остаётся доступен: `/code?view=vercel`, ссылка в «Инструментах», OAuth-редиректы работают).
- Доступность: контраст текста повышен, видимый фокус, «пропустить к содержимому», подписи у всех полей, кнопки ≥ 52 px, текст рядом с иконками, `prefers-reduced-motion`, зум страницы больше не отключён.

## Честные статусы бота
«Бот создан» → «Осталось подключить Telegram» → «Telegram подключён, бот ещё не запущен» → «Бот запущен» (только если у бота установлен webhook и Telegram не сообщает об ошибке). Nexus не хостит ботов сам — это сказано в интерфейсе, дан способ запуска на компьютере.

## Ограничения / что осталось
- Проекты хранятся в браузере (IndexedDB) — на другом устройстве их не будет. Серверного хранилища проектов нет.
- Публикация сайта требует подключённых GitHub и Vercel (GitHub App / Vercel Integration должны быть настроены администратором, см. `docs/OAUTH_SETUP.md`); автоматического хостинга ботов нет.
- ИИ работает на бесплатных моделях OpenRouter: бывают дневной лимит и перегрузка — интерфейс объясняет это и предлагает шаблон.
- Старые панели 50 инструментов и IDE не переписывались под простой язык (они в режиме разработчика).
- Светлой темы в приложении не было и не добавлялась.
- Ручная проверка скринридером не проводилась; проверены разметка, фокус и подписи, горизонтальной прокрутки на 375 px и 1280 px нет (Playwright-прогон основных сценариев).
